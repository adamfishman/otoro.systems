# otoro.systems

Website for Otoro Systems LLC. Built with [Astro](https://astro.build), edited with [Keystatic](https://keystatic.com), hosted on Cloudflare.

```bash
npm install
npm run dev     # http://localhost:4321  (content editor at /keystatic)
npm run build   # static output in dist/
```

Posts and case studies are Markdown files in `src/content/`. See [CLAUDE.md](./CLAUDE.md) for structure, conventions and deployment.
