Security Practices

Otoro Systems LLC is a single-member consulting firm providing embedded software engineering services. Otoro Systems does not host client infrastructure or store client data on its own systems.

When engaged, Otoro Systems:

  • Uses unique login credentials and strong, unique passwords for all client-related accounts
  • Enables multi-factor authentication wherever available
  • Keeps all devices and software current with security patches
  • Uses full-disk encryption (e.g. FileVault) on any device used to access client systems
  • Completes client-required security awareness and data handling training
  • Reports any suspected security incident promptly, consistent with client contractual requirements
  • Follows the client's own development, security, and data handling policies when working within client-owned environments and infrastructure
